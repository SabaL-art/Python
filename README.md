# Python Projects

A collection of Python projects I built while learning programming and software development.

## Projects

### 📁 Duplicate File Finder
Finds duplicate files by comparing their MD5 hashes.

**Features**
- Recursive folder scanning
- Duplicate file detection
- Optional duplicate file deletion

---

### 💰 Expense Tracker
A command-line expense tracker that stores transaction history in JSON format.

**Features**
- Add income
- Add expenses
- View balance
- View transaction history
- View financial summary
- Persistent storage using JSON

---

### 🐍 Snake Game
Classic Snake game built in Python.

**Features**
- Real-time gameplay
- Score tracking
- Snake growth mechanics

---

### 🗂️ File Organizer
Automatically organizes files into folders based on their file extensions.

**Categories**
- Images
- Videos
- Audios
- Documents
- Others

---

### 🎯 Hangman
A terminal-based implementation of the classic Hangman word guessing game.

**Features**
- Random word selection
- Limited lives system
- Win/Loss detection

---

### 🔐 Password Generator
Generates secure random passwords.

**Features**
- Uppercase letters
- Lowercase letters
- Numbers
- Symbols
- Custom password length

---

### 🌦️ Weather App
Fetches and displays weather information using a weather API.

**Features**
- Current weather information
- Location-based weather lookup
- API integration

---

### 🌐 Website Change Detector
Monitors a website and detects changes in its content.

**Features**
- Periodic website checking
- Content hashing using MD5
- Change detection
- Persistent storage of previous state
